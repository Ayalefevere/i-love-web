Vragenlijst/zelftest

Na elke 3 sprints (in dit geval 4 sprints) doe ik een zelftest. Ik beantwoord vragen en maak een inschatting wat ik wel en nog niet kan. Per vraag geef ik mijzelf punten.

Punten legenda

  • 🫣 0 punt = Ik ben hier nog niet aan toe gekomen
  • 😅 1 punt = Ik heb hiermee geëxperimenteerd, maar ik weet nog niet goed wat dit is.
  • 🤓 2 punten = Ik begrijp dit, maar ik kan het nog niet (helemaal) zelfstandig toepassen.
  • 🍗 3 punten = I got this

Vraag 1: Ik weet hoe ik met GitHub iteratief kan werken, gebruik issues en sub-issues, en ik kan uitleggen wat een fork, clone, commit, push, pull, merge en conflict inhouden. 🤓

🤓 2 punten

Ik weet hoe ik iteratief kan werken en ik gebruik issues. Ik weet wat forken, clonen, commiten, pushen en pullen is. Maar ik weet niet wat merge en conflict is. Daar heb ik nog niet mee gewerkt.
