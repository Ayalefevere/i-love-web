UX van HTML

Op welke verschillende manieren je afbeeldingen kunt gebruiken. Wat voor soort alt attributen horen daarbij?

  • Een normale afbeelding met src en alt als beschrijving en niet klikbaar
  • Als background-image - geen alt, omdat het in de css staat
  • Vectorafbeeldingen een svg - heeft een alt
  • Afbeelding als link - heeft een alt
  • Ineteractieve Image map - heeft twee keer een alt
  • Afbeelding met bijschrift of onderschrift - heeft ook een alt
