Donderdag 10 september

Sprint 1: Your Tribe | Project: Squad Page

Wat heb ik geleerd? Wat een media query is en hoe ze werken, wat een breakpoint is en heb geleerd dat je klein begint met bouwen zoals mobile version en dat je daarna naar desktop formaat gaat. Je opent de dev tools en als de layout niet netjes is dan voeg je een breakpoint toe. Voor mobile hoef je geen breakpoint te gebruiken.

Wat heb ik gedaan? Ik heb met studenten gekeken wat voor resolutie mijn apparaten hebben die ik nu mee heb en daarna gekeken welke devices ik gebruik en een percentage gegeven hoe veel ik het internet daarop gebruik. We moesten een nieuwsartikel openen en bekijken welke breakpoints er zijn en dat bespreken wat op valt. In onze Learning Journal heb ik een html en css bestand gemaakt om mee te oefenen. Ik moest oefenen met Media Queries in deze file. Daarna hebben we van de squad page een breakdown schets gemaakt mt html en pseudo CSS code. Daarna heb ik de schets in de issue gezet. Deze DoD heb ik in portflow gezet zoals vrijdag.

Woensdag 2 september

Sprint 1: Your Tribe | Project: Visitekaartje

Wat heb ik gedaan? Ik heb vandaag een begin gemaakt aan mijn Learning Journal. Ik heb van mijn eerdere schets een nieuwe versie gemaakt en dan als breakdown schets met alleen html tags. Daarna heb ik aan mijn eigen visitekaartje gewerkt en heb ik html dingen erin gezet en aangepast.

Studievragen

  • Wat is het nut van een breakdown schets?
  • Waar moet je opletten als je een breakdown schets maakt?
  • Wat is een breakdown schets?

Bekijk de bronnen van vandaag. Wat is het voor link en wat kan je vinden?
Bron 1 Dit gaat naar een website. Je kunt vinden welke code er in html allemaal zit, wat het doet en wat het betekent. Dit kan je helpen om een breakdown schets te maken.
Bron 2 Dit gaat naar een website. Je kunt lezen wat HTML is en wat het doet. In deze bron word uitleg gegeven hoe je eerste HTML document maakt, foto's plaatst, teksten erin zetten, lijst maken en hoe je links maakt. Je leert de basis van HTML.
Bron 3 Deze link verwijst naar een YouTube video. In deze video word verteld over semantic tags waarom en wanneer je die moet gebruiken in plaats van divs. Ook laat hij voorbeelden zien van verschillende websites welke tags er worden gebruikt. Het gaat over section, artcile en divs.

Notes H1 is de enige die maar 1 keer in een document voorkomt. Breakdown schets is een schets met alle html, css en js die je nodig gaat hebben voor je website. Doormiddel van kleuren en vlakken laat je zien wat het is en wat bij elkaar hoort.
