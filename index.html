Woensdag 2 september

Wat heb ik gedaan? Ik heb vandaag een begin gemaakt aan mijn Learning Journal in html/css. Ik heb van mijn eerdere schets een nieuwe versie gemaakt en dan als breakdown schets met alleen html tags. Daarna heb ik aan mijn eigen visitekaartje gewerkt en heb ik html dingen erin gezet en aangepast.

Studievragen

  • Wat is het nut van een breakdown schets?
  • Waar moet je opletten als je een breakdown schets maakt?
  • Wat is een breakdown schets?

Bronnen van vandaag

Wat is het voor link en wat kan je vinden in de bron?

Bron 1 Dit gaat naar een website. Je kunt vinden welke code er in html allemaal zit, wat het doet en wat het betekent. Dit kan je helpen om een breakdown schets te maken.

Bron 2 Dit gaat naar een website. Je kunt lezen wat HTML is en wat het doet. In deze bron word uitleg gegeven hoe je eerste HTML document maakt, foto's plaatst, teksten erin zetten, lijst maken en hoe je links maakt. Je leert de basis van HTML.

Bron 3 Deze link verwijst naar een YouTube video. In deze video word verteld over semantic tags waarom en wanneer je die moet gebruiken in plaats van divs. Ook laat hij voorbeelden zien van verschillende websites welke tags er worden gebruikt. Het gaat over section, artcile en divs.

Notes

H1 is de enige die maar 1 keer in een document voorkomt. Breakdown schets is een schets met alle html, css en js die je nodig gaat hebben voor je website. Doormiddel van kleuren en vlakken laat je zien wat het is en wat bij elkaar hoort.
