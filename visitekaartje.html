Project Visitekaartje

Sprint 1: Your Tribe | 31 augustus t/m 4 september 2026

De opdracht is: Maak en ontwerp een visitekaartje in HTML en CSS.

Week 1

In de analysefase heb ik de opdracht en de fases van DLC gelezen. Bij de ontwerpfase heb ik een eerste schets gemaakt van mijn visitekaartje. Later heb ik mijn definitieve schets gemaakt als breakdown schets met HTML elementen erbij en deze op GitHub Issue gezet en ik feedback gevraagd van een docent. Voordat ik kon bouwen moest ik een code editor en GitHub Dekstop downloaden. Ook heb ik de repository geforkt naar mijn account en de code gedownload naar mijn laptop.

Op donderdag tijdens het bouwen van het visitekaartje werkte ik thuis. Ik heb hem gebouwd aan de hand van mijn breakdown schets. Ik begon met de html elementen en daarna de css. Tijdens het bouwen merkte ik dat het niet zo snel ging als verwacht, want sommige code waarvan ik dacht dat het meteen goed zou werken, pakte anders uit. Het ontwerp kwam er daardoor niet direct uit te zien zoals ik wilde, waardoor ik meer tijd kwijt was aan het aanpassen. Uiteindelijk is het gelukt om mijn visitekaartje af te krijgen. Ik heb hem via GitHub live gezet. In de integratiefase heb ik gezorgd dat iedereen de aanpassingen kan zien door de repository bij te werken met GitHub Desktop.

Op vrijdag hadden we design/code review en de expo. Ik heb de visitekaartjes van medestudenten kunnen bekijken. Ik had geen feedback gekregen, maar door de expo kreeg ik inspiratie voor mijn visitekaartje. Na deze dag heb ik een stukje tekst veranderd naar icoontjes met mijn hobby's. Dat stukje bouwen duurde wel langer doordat bepaalde code niet werkte zoals ik had verwacht.

Eindresultaat

Dit is het eindresultaat van mijn visitekaartje die ik zelf heb gebouwd in HTML en CSS. Voor de vormgeving heb ik gekozen voor een CV stijl. Ik ben erg blij met het eindresultaat en tevreden. In mijn visitekaartje kun je mij leren kennen.

Learning Journal

Woensdag 2 september

Sprint 1: Your Tribe | Project: Visitekaartje | Workshop: I Love Web & Breakdown Schets

Wat heb ik gedaan?

Ik heb vandaag een begin gemaakt aan mijn Learning Journal. Ik heb van mijn eerdere schets een nieuwe versie gemaakt en dan als breakdown schets met alleen html tags. Daarna heb ik aan mijn eigen visitekaartje gewerkt en heb ik html dingen erin gezet en aangepast.

Studievragen

  • Wat is het nut van een breakdown schets?
  • Waar moet je opletten als je een breakdown schets maakt?
  • Wat is een breakdown schets?

Bekijk de bronnen van vandaag. Wat is het voor link en wat kan je vinden?

Bron 1 Dit gaat naar een website. Je kunt vinden welke code er in html allemaal zit, wat het doet en wat het betekent. Dit kan je helpen om een breakdown schets te maken.

Bron 2 Dit gaat naar een website. Je kunt lezen wat HTML is en wat het doet. In deze bron word uitleg gegeven hoe je eerste HTML document maakt, foto's plaatst, teksten erin zetten, lijst maken en hoe je links maakt. Je leert de basis van HTML.

Bron 3 Deze link verwijst naar een YouTube video. In deze video word verteld over semantic tags waarom en wanneer je die moet gebruiken in plaats van divs. Ook laat hij voorbeelden zien van verschillende websites welke tags er worden gebruikt. Het gaat over section, artcile en divs.

Notes

H1 is de enige die maar 1 keer in een document voorkomt. Breakdown schets is een schets met alle html, css en js die je nodig gaat hebben voor je website. Doormiddel van kleuren en vlakken laat je zien wat het is en wat bij elkaar hoort.
